# Google SWE Interview Prep A 12-week plan built around the rounds Google actually runs: phone screen, coding onsites, system design (L5, sometimes L4), and Googleyness & Leadership. Budget is about 2 hours on weekdays and 5–6 hours on weekend days. Tick tasks as you go; progress is saved in this browser. **First action this week:** ask your recruiter which level you're being interviewed for, and whether the loop includes a standalone system design round. That single answer decides how much time goes to system design. With \~4–5 years of experience you're likely slotted L4 or L5. If you're targeting L5, make sure the loop has system design; candidates report L4 loops being scheduled by default unless they ask. ## The pipeline | Stage | Format | What it tests | Who gets it | | --- | --- | --- | --- | | Recruiter screen | 15–30 min call | Background, level, timeline | Everyone | | Online assessment | 2 problems, 60–90 min | Basic DSA, speed | Mostly new grads / university hiring | | Technical phone screen | 45 min, 1–2 problems in a shared doc, no code execution | Coding + communication | Everyone (L5 often gets two) | | Onsite: Coding ×2–3 | 45 min each | DSA, clean code, testing, follow-ups | Everyone | | Onsite: System design | 45–60 min | Architecture, trade-offs, scale | L5+ standalone;
